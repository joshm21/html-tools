Tools Collection

A set of utility web pages hosted on GitHub Pages.

  • Multi-Crop Image

    Interactive tool to detect and crop multiple regions from an image horizontally or vertically.

  • Random Media Player

    Shuffle and randomly play local MP4 video or MP3 audio files.

  • Media Splitter

    Split audio or video files into custom timestamp segments and export them as a CSV file.

  • Text Splitter (Consecutive Numbers)

    Parse and split text blocks separated by consecutive numbers into an organized table.
